# 2d2

2d2, a powerful and versatile Discord bot written in Python.

## Installation

For compiled version:

- Download the latest version from [Releases](https://github.com/its-case/2d2/releases/tag/v4.0.0)
- Extract all the contents
- Open `token.txt.txt`
- Enter your Discord bot token
- Run `2d2_v4.0.0.exe`

For Python version:

- Install the required modules from `requirements.txt`
- Provide your Discord bot token in `token.txt.txt`
- Configure the bot settings and presets
- Run the Python source code

## Features

- Discord server management
- Server information
- Channel management
- Role management
- Message management
- Preset system
- Custom server settings
- GUI dashboard
- Server and bot status
- Configuration management

## Requirements

- Python 3.13.16
- CustomTkinter 6.0.0
- discord.py 2.7.1
- Pillow 12.3.0
- PyInstaller 6.22.3
